# Data

The training dataset and the deterministic compressor that bridges the onboarding survey to the Context block the model sees at runtime.

## Files

- **`memory_moment_train_v5.jsonl`** — ~500 training rows, one JSON object per line. Each row is a full prompt/response pair in the chat-template format the fine-tune expects.
- **`compress_v5.py`** — pure-Python function that takes a survey JSON (10 fields) and emits a Context block. ~50 lines. No LLM in the path — it's templating.

## Row schema

Every training row has this shape:

```json
{
  "messages": [
    {"role": "system", "content": "<system prompt>"},
    {"role": "user", "content": "Context: <compressed context block>\nSituation: <hard moment>"},
    {"role": "assistant", "content": "🤝 <line 1>\n🙂 <line 2>\n🫱 <line 3>"}
  ]
}
```

The system prompt is the same across every row — see [`../serving/Modelfile`](../serving/Modelfile) for the canonical version.

## The five modes

Each output line is prefixed with one of five mode tags:

| Tag | Mode | When to use |
|---|---|---|
| 🤝 | agree-and-move | Don't argue with the feeling; redirect after acknowledging |
| 🙂 | lighten | A small, voice-true joke — never at the loved one's expense |
| 🫱 | redirect | Shift attention to a concrete next thing |
| 🛑 | firm-but-kind | When safety or boundaries actually matter |
| 🎯 | distract | Pull toward something they care about |

The fine-tuned model picks 3–5 modes per situation — never all five — based on what fits.

## The Context block

The Context block is the runtime input to the line-generator. It's a compressed view of the loved one — name, relationship, voice, things they say, what calms them, what to avoid. It's built once at onboarding by `compress_v5.py` and cached on device. The training rows contain Context blocks generated by the same function, so what the model saw at training time matches what it sees at inference time.

Example:

```
Your mother. You call her Mom.
She often says: "Don't fuss." / "He means well." / "I'll do it in a minute."
Calms with: tea, the garden, photos of the grandkids.
Avoid: rushing her, mentioning the move, talking about Dad's accident.
```

## Building the dataset

The dataset was built through a human-in-the-loop process — generated in batches with GPT-4 against a strict system prompt, then reviewed line-by-line in a CSV, with notes flagging any line that needed regeneration. Lines without notes were never rewritten. The full workflow is documented in past iterations of the project; the deliverable here is the final reviewed JSONL.

## Why no LLM in compression

An earlier version of this project used a second Gemma 4 call to compress the survey into a Context block. That added latency, hallucination risk, and a second failure mode at runtime. The deterministic function has none of those problems and produces output that's reproducible bit-for-bit — which matters because every training row's Context can be traced back to a survey JSON and verified.
